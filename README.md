# 음악 시간 첫걸음 — 중1 음악 진단·교정 도구

중학교 1학년 음악 수업을 위한 **진단 · 오답 분석 · 교정 · 재진단** 웹 프로토타입입니다.
교육공학 창의개발랩 중간발표 산출물로, 학생의 **음악 학습 사고회로에서 끊긴 곳**을 찾아 잇는 데 초점을 두었습니다.

- **사이트**: https://<아이디>.github.io/<저장소이름>/ (배포 후)
- **발표 자료**: `presentation/` (슬라이드 7장, HTML)
- **발표 대본**: `docs/presentation-script.pdf` (7장·9~10분)
- **문항 명세서**: `docs/item-spec.pdf` (38문항 + 청음 8문항)

## 무엇을 하는 도구인가

학생의 음악 학습은 다섯 단계를 돕니다.
① 듣고 지각 → ② 악보를 소리로 바꾸기 → ③ 7요소 어휘로 개념 붙이기 → ④ 부르고 연주하기 → ⑤ 스스로 점검하고 고치기

이 도구는 **②번을 먼저 진단하고, ⑤번을 훈련**시킵니다. 교과 진도를 대체하지 않고, 수업 마지막 10분을 "내 보충 카드"로 쓰게 합니다.

## 화면 (탭 3개)

| 탭 | 하위 메뉴 | 내용 |
|---|---|---|
| **홈** | — | 상태에 맞는 '다음 할 일' 한 가지 |
| **진단** | 진행 순서 / 진단 / 결과 | 기초 문해력 3문항 + 7요소 적응형(10~17문항, 약 3분) |
| **학습** | 오답 분석 / 영상 과제 / 심화 / 바로잡기 / 개념 학습 / 청음 | 틀린 곳 확인 → 교정 → 확장 |

## 진단 설계

- **1단계 기초 문해력 3문항** — 높은음자리표·낮은음자리표 계이름, 박자표 읽기. **오선 악보를 그림으로 함께** 제시해 글만 읽고 풀 수 없게 했습니다.
- **2단계 7요소 35문항** — 요소당 5문항(하·중·상). 리듬·가락·화성·형식·셈여림·빠르기·음색
- **적응형 출제** — 요소마다 '중' 기본 문항 1개 → 정답이면 즉시 다음 요소 통과, 오답이면 '하' 기초 문항 1개 추가
- **점수** — 기본 정답 100 · 기초 정답 50 · 둘 다 오답 0 · 건너뛰면 '미확인'
- **오개념 태그** — 오답 선택지마다 유형을 붙여, 리포트가 **오개념**과 **아직 배우지 못한 부분**을 구분합니다.

## 교정과 확장

- **바로잡기 3단계** — ① 같은 유형 한 번 더 ② 비슷한 개념과 구별하기 ③ 손으로 쓰기(단답형)
- **확인 문제를 틀리면 넘어가지 않음** — 완료 버튼이 잠기고 '한 번 더 풀어보기'가 나옵니다.
- **진단 기반 챗** — 학생의 오답·고른 답·약점 요소를 알고 답합니다. `지금 화면 봐줘` → 지금 화면(문제 원문·악보·고른 답)을 읽고 분석, `왜 틀렸어요?` → 오답 이유, `다시 설명` → 비유 → 단계별 풀이 → 예시로 방식이 바뀝니다.
- **맞춤 영상** — 진단이 낮은 요소 순서로 영상 배치, '이해됐나요?' 1탭 → 안 되면 챗으로 연결
- **심화** — 잘하는 요소는 심화 개념 + 악보 + '귀로 확인하기'
- **청음 8문항** — Web Audio로 그 자리에서 소리를 합성합니다(음원 파일 없음).
- **재진단** — 이전 점수와 비교해 `↑ 이전보다 +N점` 표시

## 배포 방법 (GitHub Pages)

1. GitHub에서 **New repository** → 이름 입력(예: `music-first-step`) → **Public** → Create
2. **Add file ▸ Upload files** → 이 폴더의 내용물(`index.html`, `README.md`, `.nojekyll`, `docs/`, `assets/`, `presentation/`)을 끌어다 놓기 → Commit
3. **Settings ▸ Pages** → Source `Deploy from a branch`, Branch **main** / **/(root)** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/music-first-step/`

> `.nojekyll`은 이름이 점으로 시작해 업로드 목록에 안 보일 수 있습니다. 빠져도 앱은 동작합니다.

## 참고

- 폰트는 Google Fonts(Gothic A1, IBM Plex Sans KR, Gowun Batang, Noto Music)와 Bravura(악보 기호)를 불러옵니다. 인터넷이 없으면 시스템 폰트로 대체됩니다.
- 학생 응답은 **브라우저에만** 저장됩니다(서버·회원가입 없음).
- 챗은 **규칙 기반**입니다. 외부 LLM을 붙이려면 `answerFor()` 한 곳만 교체하면 됩니다.
- 영상은 유튜브 임베드이므로 학교 네트워크에서 차단될 수 있습니다.
