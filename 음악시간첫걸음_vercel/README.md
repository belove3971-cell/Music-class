# 음악 시간 첫걸음 — 중1 음악 진단·맞춤 학습

중학교 1학년을 위한 **음악 진단 · 맞춤 학습 웹앱** 프로토타입입니다.
교육공학 창의개발랩 과제물로, 3주차에 배운 **인지과학 및 UI/UX 이론**에 근거해 설계했습니다.

- **대상**: 중학교 1학년 (초등 음악 경험이 서로 다른 학생들)
- **목표**: 악보 읽기 기본기(기초 문해력)와 7요소를 진단으로 확인하고, **취약한 부분만 골라** 바로 학습
- **구성**: 파일 하나(`index.html`)로 동작하는 프로토타입. 설치·서버 없이 브라우저에서 바로 실행됩니다.

## 바로 보기 (GitHub Pages)

이 저장소를 GitHub에 올리고 Pages를 켜면 아래 주소로 누구나 접속할 수 있습니다.

```
https://<깃허브아이디>.github.io/<저장소이름>/
```

## 배포 방법 (5단계)

1. [github.com](https://github.com) 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 예: `music-first-step` 입력 → **Public** 선택 → **Create repository**
3. 저장소 화면에서 **Add file ▸ Upload files** → 이 폴더의 `index.html`, `README.md`, `.nojekyll`, `docs/` 폴더를 **끌어다 놓기** → 아래 **Commit changes**
   - 파일 이름이 반드시 **`index.html`** 이어야 주소 뒤에 파일명이 붙지 않습니다.
   - `.nojekyll` 은 이름이 점으로 시작해 업로드 화면에서 안 보일 수 있습니다. 빠져도 동작에는 지장이 없습니다.
4. 저장소의 **Settings ▸ Pages** → *Source* 를 **Deploy from a branch**, *Branch* 를 **main** / **/(root)** 로 지정 → **Save**
5. 1~2분 뒤 **Actions** 탭이 초록색이 되면, 위 주소로 접속됩니다.

> 수정할 때: 파일을 다시 업로드(또는 파일 내용을 Edit)하고 Commit하면 1분 안에 사이트가 갱신됩니다.

### 더 빠른 대안
- **Netlify Drop** — [app.netlify.com/drop](https://app.netlify.com/drop) 에 `index.html` 을 끌어다 놓으면 즉시 주소가 생깁니다.
- **파일로 배포** — 과제 제출용이라면 `index.html` 을 그대로 첨부해도 됩니다. 받는 사람이 내려받아 더블클릭하면 그대로 실행됩니다.

## 진단 문항 (38문항 · 적응형)

**1단계 기초 문해력 3문항** — 높은음자리표·낮은음자리표 계이름, 박자표 읽기 (오선 악보를 그림으로 제시)

**2단계 7요소 35문항** — 요소당 5문항, 난이도 하 7 · 중 21 · 상 7
- 학년군 위계: 초3~4 연계 10 · 초5~6 연계 10 · 중1 15문항
- 교육과정 연계: 여러 가지 박자, 장단의 세, 여러 지역의 토리, 여러 가지 시김새, 딸림7화음, 종지, 형식(ABA·론도·변주곡·한배), 셈여림의 변화, 빠르기의 변화, 여러 가지 음색

**적응형 출제 규칙**
- 요소마다 난이도 ‘중’ 기본 문항 1개로 시작
- **정답이면 즉시 다음 요소로 통과** (아는 것을 반복해 묻지 않음)
- 오답이면 ‘하’ 기초 문항 1개 추가
- 총 10~17문항, 대부분 10~12문항 (약 3분)
- 건너뛰기는 ‘미확인’으로 기록하고 강제로 막지 않음(포스텔의 법칙)
- 점수: 기본 정답 100점 · 기초 정답 50점 · 둘 다 오답 0점 · 미확인은 점수 없음

문항을 바꾸려면 `index.html` 안의 **`ITEM_BANK`**(7요소)와 **`LITERACY`**(악보 읽기) 배열에서 발문(`q`)·선택지(`opts`)·정답 번호(`ans`)·해설(`why`)만 수정하면 됩니다. 채점과 결과 그래프가 자동으로 연동됩니다.
