# MY PACE — 퀘스트형 자기조절학습 앱

AI가 답이나 계획을 대신 만들지 않고, **질문과 선택지로 학습자가 스스로 계획·실행·점검·성찰하도록** 돕는 학습 앱입니다.
입력은 거의 모두 선택형이며, 앱은 공부 **앞뒤에** 잠깐 쓰고 공부하는 동안에는 닫아 두어도 됩니다.

## 실행
빌드 없는 정적 사이트입니다. `index.html`을 열거나 GitHub Pages의 `/my-pace/` 경로로 접속하세요.
기록은 사용자의 브라우저(localStorage)에만 저장됩니다.

## 퀘스트 흐름
| 장 | 이름 (SRL 단계) | 학습자가 하는 일 |
|---|---|---|
| 1장 | 지도 그리기 (계획) | 컨디션 → 과제 유형 → 하는 이유 → **학습 과정 지도**에서 오늘 할 단계 선택 → 양·확인 방법·시간 → 예상 달성도 |
| 2장 | 탐험하기 (실행) | 타이머 시작 후 앱은 닫아도 됨. 정복한 단계 표시. 막히면 **구출 미션** |
| 3장 | 보물 확인 (점검) | 정한 방법으로 확인했는지, 실제 달성도, 집중도·난이도 → 예상과 비교 |
| 4장 | 탐험 일지 (성찰) | 도움 된 단계·막힌 단계·이유·다음 전략 선택, 한 줄은 선택 |

## 과제 유형별 학습 과정 지도 (`coach.js`)
문제 풀이 / 암기 / 읽고 이해 / 글쓰기·보고서 / 실기 연습 / 발표·프로젝트. 유형마다 5단계의 일반적인 학습 과정이 있고,
단계마다 질문(q)·팁(tip)·방법 예시(how)가 있어 코치가 학습자가 고른 단계에 맞춰 조언합니다.

## 동기 설계 (Keller의 ARCS 모형 기반)
| ARCS | 구현 |
|---|---|
| 주의(Attention) | 퀘스트·장 이름, 클리어 보상 화면, 오늘의 미션 |
| 관련성(Relevance) | '이 퀘스트를 하는 이유' 선택 → 막혔을 때 다시 보여 줌 (과제 가치) |
| 자신감(Confidence) | 작은 단계로 쪼갠 학습 지도, 구출 미션(2분 미션·목표 줄이기), 지금까지의 진척과 과거 회복 경험 상기, 능력이 아닌 방법 탓으로 다시 보기(귀인) |
| 만족감(Satisfaction) | 경험치·레벨·배지, 단계 정복 표시, 예상과 실제가 가까워지는 성장 그래프 (남이 아닌 과거의 나와 비교) |

보상 원칙: 경험치는 **자기조절 행동**(계획, 예측, 직접 확인, 회복, 성찰)에만 줍니다. 높은 달성도 자체에는 주지 않아 자기평가를 부풀릴 이유를 없앴고,
AI를 썼다고 점수를 깎지도 않습니다. 정확하게 예측할수록 보상이 커집니다.

## 막혔을 때 (구출 미션)
단계 → 기분 → 이유를 고르면 ① 기분에 맞는 응원과 귀인 재구성 ② 진척 상기와 '내가 고른 이유' ③ 단계 맞춤 질문(지원 수준별 팁·방법)
④ 구출 미션 4개(내 약속 지키기, 2분 미션, 방법 바꾸기, 목표 줄이기, 5분 쉬기 중)가 나옵니다. 미션 성공 시 회복력 경험치와 배지.

## 파일
- `coach.js` — 학습 과정 지도와 규칙 기반 코치 (실제 LLM으로 교체 가능)
- `quest.js` — 경험치·레벨·배지·오늘의 미션
- `app.js` — 화면과 저장
- `style.css` — 라이트/다크 테마
