# MY PACE — AI 기반 자기조절학습 지원 웹앱

AI가 답이나 계획을 대신 만들어 주지 않고, **질문으로 학습자의 자기조절과 메타인지를 이끄는** 학습 앱입니다.
교육공학 창의개발랩 팀 프로젝트의 실제 구현본입니다.

## 실행
빌드가 필요 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나 GitHub Pages에서 `/my-pace/` 경로로 접속하세요.
모든 기록은 사용자의 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## 흐름
| 화면 | 내용 | 외주화 방지 장치 |
|---|---|---|
| 온보딩 1 | 어려운 점 선택 + 실제 순간 서술 + 원인 짐작 | 직접 쓰기 전에는 AI 질문·다음 버튼 잠김 |
| 온보딩 2 | AI 도움 수준 선택 (질문만 / +단계 힌트 / +빈칸 구조) | 어떤 수준에서도 완성된 답 없음 |
| 온보딩 3 | 막혔을 때의 첫 행동 (if-then) 약속 | AI보다 내 행동이 먼저 |
| 계획 | 컨디션 → AI 질문에 답 → 목표 직접 작성·자기점검 → 시간·예상 달성도 | 목표 대신 써 주기 없음, AI 비교는 수준별 횟수 제한 |
| 실행 | 집중 타이머, 과정 기록, 막힘 기록 | 막힌 지점을 10자 이상 먼저 써야 AI 질문 |
| 점검 | 실제 달성도 자기평가 + 판단 근거 → 예상과 비교 | 근거를 써야 비교 가능 |
| 성찰 | AI 질문 2~3개에 답 + 다음 전략 직접 작성 | 전략은 학습자가 결정 |
| 성장 | 예상 vs 실제 그래프, AI 사용량, 직접 쓴 글자 수, 전략 기록 | 의존 정도를 스스로 모니터링 |

3회 학습마다 AI 사용량을 보고 도움 수준을 줄이거나 늘릴지 **제안**하며, 결정은 학습자가 합니다(스캐폴딩·페이딩 + 자율성).

## 파일
- `coach.js` — 규칙 기반 코치 엔진. 실제 LLM으로 교체할 때도 같은 입력·출력과 원칙(정답 금지, 학습자 입력 우선)을 유지합니다.
- `app.js` — 화면과 저장 로직
- `style.css` — 라이트/다크 테마
